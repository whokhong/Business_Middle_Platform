移动端首页 v2 说明（打破门户范式）

范式①：数据罗列 → 规则简报（V1.5 方案 A）。首屏「今日简报」按紧迫度排序，可展开明细；接口口径 GET /v1/portal/brief?source=rule。
范式②：应用导航 → 意图流。横向滚动的意图胶囊（发起审批 / 查合同 / 找人…）取代金刚区；应用宫格降级到页面底部/抽屉。
范式③：均匀栅格 → 时间轴 + 视觉权重。首屏一张「最紧急事项大卡」，其余按「今天必须做 / 本周 / 知悉」分组，权重逐级递减。
手势：顶部下拉刷新简报；待办右滑完成 / 左滑稍后；底部固定行动栏在滚动后出现（回顶收起），对最紧急项一键处理。右下角 ✨ FAB 为 AI 助手（A1-F02-9 · 验收演示默认开启，生产可配置关）。
全局导航：底部 Tab 栏五项（首页 / 待办 / 审批 / 消息 / 我的），与 PC 顶栏 renderTopbar 一一对应；待办 / 审批 / 消息带未读角标（为 0 不显示）。Tab 栏位于屏容器与 home indicator 之间，天然不遮挡内容；行动栏坐落于 Tab 栏之上，二者不重叠。
钉钉容器兼容：保留状态栏、钉钉导航栏、home indicator 与免登演示层。
