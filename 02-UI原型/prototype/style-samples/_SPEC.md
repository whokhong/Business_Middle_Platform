# 应用中心视觉样稿 · 共享内容规格

> **目的**：产出 4 张「应用中心」视觉样稿供客户选型。**内容结构、文案、数据、区块顺序必须完全一致**，只有视觉风格不同——否则无法公平对比。
> **硬约束**：纯 HTML 单文件、内联 `<style>`、零依赖（无 CDN / 无构建 / 无外链字体）、系统字体、浅色或深色按风格定、真实可打开。

## 二、四张样稿的风格差异（仅视觉）

| 样稿文件 | 风格 | 基调 |
|---|---|---|
| `sample-apple.html` | **Apple 风** | 大留白、胶囊圆角(980px 用于胶囊/链接)、光学字号、负字间距、毛玻璃导航、**麓邦红 #C8161D 作唯一强调色**（不做背景铺色） |
| `sample-vercel.html` | **Vercel 风** | 黑白极简、`shadow-as-border` 替代边框、极端负字间距、缺少彩色、**麓邦红仅用于极少关键动作** |
| `sample-notion.html` | **Notion·Claude 风** | 暖白底(#f6f5f4 系)、暖中性色阶、细边框(1px rgba(0,0,0,.1))、阅读优先、**赤陶/暖调强调或麓邦红暖化** |
| `sample-dark.html` | **深色科技风（Linear/Raycast 系）** | 深色底、1px 细边框、**麓邦红 #C8161D 作高亮**、键盘优先气质、近白文字(#f7f8f8) |

### 各风格关键参数（务必按此落地）

**Apple 风**
- 背景：页面 `#f5f5f7`，卡片 `#ffffff` 或 `#f5f5f7`
- 正文色 `#1d1d1f`；次要文字 `rgba(0,0,0,.48)`
- 强调色：**麓邦红 `#C8161D`**（仅用于交互元素、胶囊链接、AI 徽标）
- 字体：`-apple-system, "SF Pro Display", "PingFang SC", sans-serif`
- 字号：主标题 40px/600/行高1.10/字距 normal；卡片标题 21px/600；正文 17px/400/行高1.47/**字距 -0.374px**；说明 14px/400/字距 -0.224px；小字 12px/字距 -0.12px
- 圆角：卡片 8px、输入框 11px、面板 12px、胶囊 980px
- 阴影：极克制，仅 `rgba(0,0,0,.22) 3px 5px 30px 0px` 用于悬浮元素；多数元素**无阴影**，靠背景色差分层
- 导航：`rgba(255,255,255,.72)` + `backdrop-filter: saturate(180%) blur(20px)`
- 禁：不要加边框、不要多色、不要重阴影、不要渐变纹理

**Vercel 风**
- 背景：`#ffffff`；文本 `#171717`（**不用纯黑**）；次要 `#666666`
- 强调：麓邦红 `#C8161D` 仅用于**极少数**关键动作（如推荐卡的「立即打开」）
- 字体：`"Geist", Inter, -apple-system, "PingFang SC", sans-serif`
- 字号：主标题 48px/600/**字距 -2.4px**；正文 16px/400；小字 14px
- **边框用 shadow-as-border**：`box-shadow: rgba(0,0,0,.08) 0px 0px 0px 1px`（**禁止** `border:1px solid`）
- 卡片阴影多层堆栈：`rgba(0,0,0,.08) 0 0 0 1px, rgba(0,0,0,.04) 0 2px 4px, #fafafa 0 0 0 1px inset`
- 圆角保守：2px/6px/8px
- 字重仅 400/500/600（**禁 700**）

**Notion·Claude 风**
- 背景：`#ffffff`，区块底 `#f6f5f4`（暖白，带黄褐底调）；文本 `rgba(0,0,0,.95)`
- 暖中性：`#31302e`、`#615d59`、`#a39e98`
- 强调：麓邦红**暖化使用**（可直接用 `#C8161D`，或搭配暖橙 `#dd5b00` 作辅助暖调）
- 字体：`Inter, -apple-system, "PingFang SC", sans-serif`；标题可选衬线感更强的字重
- 字号：主标题 48px/700/**字距 -1.5px**；卡片标题 22px/700/字距 -0.25px；正文 16px/400/行高1.5；徽标 12px/600/**字距 +0.125px**
- 边框：`1px solid rgba(0,0,0,.1)`（**细如耳语**，贯穿使用）
- 阴影多层低透明度（累计 ≤0.05）：`rgba(0,0,0,.04) 0 4px 18px, rgba(0,0,0,.027) 0 2px 8px, rgba(0,0,0,.02) 0 .8px 3px`
- 胶囊徽标（9999px 圆角）用于状态/标签

**深色科技风**
- 背景：页面 `#08090a`，面板 `#0f1011`，提面 `#191a1b`，次表面 `#28282c`
- 文字：主 `#f7f8f8`，次 `#8a8f98`，弱 `#62666d`
- 强调：**麓邦红 `#C8161D`**（作高亮/激活/CTA），可配合其亮化变体 `#E4453A` 保证深色下可读性
- 字体：`Inter, -apple-system, "PingFang SC", sans-serif`
- 字号：主标题 40px/600/字距 -1.5px；正文 15px/400；小字 13px
- 边框：`1px solid rgba(255,255,255,.06)`（**极淡，靠边框而非阴影分层**）
- **禁止用阴影造深度**，深度靠表面色阶差（#08090a → #0f1011 → #191a1b → #28282c）
- 圆角 6px/8px
- 卡片悬浮态：边框提亮至 `rgba(255,255,255,.12)`
