# 业务系统可调用能力清单

> **文档说明**  
> - **读者**：业务系统 / 存量系统接入负责人、后端与集成研发。  
> - **目的**：汇总经 **E1 API 网关** 对外暴露、可在 **应用注册** 中勾选的中台 **Open API** 与 **领域事件**（与 `platform-capabilities` 原型目录同源维护）。  
> - **统计口径**：**能力域** = 本文 §2 总览表行数（接入导向分组，**不等同** PRD 129 个顶层功能点）；**API** = `HTTP 方法 + 路径` 去重（路径参数统一写作 `{id}` / `{taskId}` 等，各写法计一条）；**事件** = `事件码` 去重。  
> - **真源优先级**：《麓邦业务中台产品PRD》v2.1 > 原型 `prototype/assets/mock.js`（`platformApis` / `platformEvents`）> 《应用接入四域-产品技术方案》。  
> - **边界**：本文 **不替代** OpenAPI 详设、错误码表与请求/响应 Schema；契约以详细设计与网关发布为准。  
> - **日期**：2026-10-21

## 1. 文档说明（接入方阅读指引）

1. **先注册**：`I1` 五 step 申请 → 审批 → 领取 `client_id` / `app_secret` → 配置回调域名白名单（`I1-F06`）。  
2. **再 SSO**：新系统 OIDC（`B1-F02`）；存量 `B1-F03` + `POST /v1/auth/ticket/exchange`（见《应用接入四域》域二）。  
3. **能力调用**：按七步 Checklist（PRD §4.6）按需接入主数据、权限、待办、消息、文件、工作流、审计；**数据权限行级范围留在业务库**（§10.4 #6）。  
4. **观测分链**：合规 **`POST /audit/log`（E2）** ≠ 集成排障 **J3 `event_outbox`** ≠ 产品分析 **`POST /v1/portal/behavior`（A1-F05，非业务后端必接）**。
