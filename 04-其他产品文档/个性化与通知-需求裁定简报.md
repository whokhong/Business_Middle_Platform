## 三、需求细化方向（主理人裁定，供 PRD 展开）

### 需求 A：千人千面（AI 智能推荐排序）

**核心机制**：AI 依据用户行为自动调整首页，**无需人工配置**。

- **输入信号**（产品侧定义）：应用打开频次与时段、待办处理习惯、意图流使用分布、常访问内容类型
- **输出效果**：
  - 应用排序自适应（常用前置）
  - 「AI 为你推荐」区（已有雏形，见应用中心样稿）扩展到首页
  - 首页时间轴流的**权重微调**（用户常处理的类型适度前置）
- **硬边界（必须守住）**：
  - **AI 只调"顺序与推荐"，不改"结构"**——卡片集合、三栏结构、权限过滤均由角色模板与权限决定，AI **不得**增删卡片、不得越过权限
  - **无权限内容绝不推荐**（权限是硬约束，AI 只能在其可见范围内排序）
  - **可关闭**：用户可关掉 AI 推荐（回到固定排序）
  - **可解释**：推荐要有理由（沿用应用中心样稿的"推荐理由"设计，如"你每周一上午都会打开它"）
- **冷启动**：新用户无行为数据时，退化为角色模板默认排序（不假装有推荐）

### 需求 B：个人界面风格定制（轻定制）

在既有「首页个性化」（布局）之外，新增「**界面风格**」：

| 维度 | 选项 | 说明 |
|---|---|---|
| **主题色** | 麓邦红（默认）/ 若干预设色（如靛蓝 / 石墨灰 / 暖橙） | 影响强调色、激活态、链接色；**语义色（成功/警告/错误）不随之改变**（保持语义稳定） |
| **内容密度** | 宽松 / 标准（默认）/ 紧凑 | 影响行高、内边距、卡片间距 |
| **圆角** | 直角（4px）/ 标准（8px，默认）/ 圆润（12px） | 影响卡片、按钮、输入框 |

**硬边界**：
- **不做暗色模式**（守决议 #3）
- **语义色不改**（成功/警告/错误保持固定，避免"红色不警示了"的危险）
- **换肤不改变布局与功能**，只改变视觉 Token
- **落在 `--bmp-*` Token 层**（既有约定：全部走 CSS 变量，未来可扩展）
- 设置持久化：建议 `localStorage`（原型）/ `user_preference` 服务端字段（正式）

### 需求 C：通知 Banner（首页顶部）

| 项 | 规则 |
|---|---|
| **展示位置** | PC 首页顶部 + 移动端首页顶部（紧接顶栏/导航栏之下） |
| **显隐条件** | **有已发布且未过期的公告 → 显示；无 → 完全不占位（不显示空横条）** |
| **内容** | 公告标题 + 简短摘要 + 类型标签（通知/新闻/紧急）+ 发布时间 + 「查看详情」 |
| **多条时** | 支持轮播/堆叠切换（多条公告循环展示） |
| **可关闭** | 用户可关闭（当次会话内不再显示同一条；建议记录已关闭的公告 id） |
| **置顶优先** | 复用 `MOCK.notices` 的 `top` 字段，置顶公告优先展示 |
| **后台管理** | 增强既有 `PAGES["notices-admin"]`（公告管理）：新增 **「是否在 Banner 展示」开关** + **Banner 展示时段**（起止时间）+ **Banner 排序/优先级** + Banner 预览 |

### 需求 D：登录页改造（Notion 风格 + 增强）

- **视觉**：改造为 Notion·Claude 暖色极简（暖白 `#f6f5f4`、`1px solid rgba(0,0,0,.1)` 细边框、压缩字距、多层低透明度阴影），替换现有红渐变品牌区
- **增强**：① 钉钉扫码作为**主推方式**（默认落在扫码 Tab 或更突出）② 登录页可展示 **公司新闻/通知 banner**（未登录也能看到公司要闻）
- **不删功能**：密码登录、企微扫码、第三方 OAuth、失败计数、图片验证码、锁定、MFA、redirect 回跳——**全部保留**

## 五、判断标准（验收）

1. **千人千面**：能演示"AI 排序 vs 固定排序"的差异，且推荐有理由、可关闭、不越权限
2. **风格定制**：切换主题色/密度/圆角，**立即全局生效**且刷新后保持；语义色不随之改变
3. **Banner**：有条目时显示、无条目时**完全不占位**（含空态验证）；可关闭；后台可控制显隐
4. **登录页**：Notion 风格落地，钉钉扫码为主推，**原有功能一个不少**（失败计数/锁定/MFA 回归可用）
