## 〇、通用验收标准（所有页面共用，逐页走查不重复列出）

| # | 验收项 | 标准 |
| --- | --- | --- |
| G1 | Token 一致性 | 全部色值/字号/间距/圆角/阴影引用 `--bmp-*` Token（值指向 Notion 暖色第一轨），无硬编码；品牌红 `#C8161D` 与 danger 亮红 `#F53F3F` 职责不混用（UIUX 2.1 五条规则）；**紧急/超时用品牌红、错误/失败用 danger（UIUX 2.1 第 3 条）**；细边框 `1px solid rgba(0,0,0,.1)` 优先于重阴影；徽标字距 `+0.125px`、标题负字距 |
| G2 | 5 态覆盖 | 加载=骨架屏；空态=插图+说明+引导按钮；错误=错误码+重试；无权限=锁形+申请入口 |
| G3 | 反馈规范 | 成功 Message 2s / 失败 3s；高危操作 HighRiskConfirm（输入确认+具体动词按钮） |
| G4 | 权限表达 | 无权限按钮隐藏（或禁用+tooltip「无权限，可申请」）；菜单按权限动态渲染 |
| G5 | 文案规范 | 动词开头、错误提示含原因+解决方法、时间 24h 制、列表相对时间+hover 绝对时间 |
| G6 | 可访问性 | 正文对比度 ≥4.5:1；弹窗 Esc 关闭、焦点圈定；Tab 顺序符合视觉流 |
| G7 | 命名规范 | Figma 页面命名 `BMP / {端} / {页面ID} {页面名} / {状态}` |

## 一、批次 1：员工高频闭环（7 页，先行启动）

### T1-01 UI-LOGIN-01 统一登录页

- **设计要点**：左 60% 品牌区（红色 Logo+宣传语）/ 右 40% 登录卡；密码登录与扫码登录双 Tab；第三方钉钉/企微入口
- **交互重点**：失败 3 次出图片验证码 → 5 次锁定提示；「记住账号」仅记用户名；redirect 回跳
- **专属验收**：① 锁定文案含剩余时间；② 扫码 Tab 展示轮询状态（待扫码/已扫码待确认/过期刷新）；③ 未启用的第三方渠道按钮不渲染；④ 登录按钮 loading 防重复提交
- **依赖**：Logo 源文件（精确红）；无则占位红先行
- **工作量**：1.5d（视觉 1 + 交互标注 0.5）

### T1-02 UI-A1-01 工作台首页（布局引擎，**重构版 v2**）

- **设计要点（v2 三栏）**：顶栏 56px 毛玻璃 sticky + 内容区 max-width 1440px 居中 + **三栏**（左：AI 今日简报 + 意图流 + 全部应用 / 中：紧迫度时间轴流（主区）/ 右：我的订阅 + 关注与动态 + 本月速览）；每栏为独立 24 栅格容器
- **交互重点**：编辑模式（**跨栏禁拖拽**，栏内可拖拽排序/显隐/栅格 12/16/24、恢复默认模板）；单卡片失败降级占位不影响整页；角标 30s 轮询；⌘K 命令栏全局唤起
- **专属验收**：① **三检验**：三秒检验（首屏无滚动可见简报第一句）/ 一句话检验（意图动作≤1 跳到目标）/ 权重检验（「今天必须做」行高 ≥「知悉即可」×1.5，首屏无等大方块阵列）；② AI 简报四段结构（问候→判断句→①②逐项→收尾「其余 N 件」），必说 2–3 件、上限 3 件；③ **诚实原则**：AI 不可用/超时/数据不足时不生成判断文案、**不显示 AI 徽标**，降级模板句 + 小字「AI 暂不可用，已按待办时限排序」；④ 时间轴流三组四维同步衰减（72/56/44px + 色条 品牌红/暖橙/细线 + 字号 + 按钮）；⑤ 超时项**不自动霸占首位**（红色「已超时 Xh」标注 + 简报显式提一句）；⑥ **公告/消息不进时间轴流**（只入右栏）；⑦ 编辑模式保存/取消二次确认；⑧ **不删除任何既有 cardId**（`todo-list`/`notice-msg`/`birthday`/`data-metrics`/`frequent-apps`/`quick-stats` 收 `legacy` 区 `visible:false`），v1 模板平铺不报错
- **依赖**：布局引擎 `template_json version:2`（待架构师确认，见 PRD 10.5.4 Q1）；卡片 `ai-brief`/`intent-stream`/`urgency-stream`/`watch-list`/`my-subscriptions`/`all-apps` 注册进 `cardManifest`
- **工作量**：3d（本项目交互最复杂页面之一）
- **状态**：**重构版 v2（新增结构，页面 ID 不变）**

### T1-03 UI-A4-01 统一待办中心

- **设计要点**：三视图 Tab（待办/已办/我发起的）+ 筛选（来源/类型/紧急度/搜索）+ 待办卡列表 + 批量浮条
- **交互重点**：去处理=新标签页跳源系统；催办 24h 去重（重复点击提示「今日已催办」）；临期/超时置顶标红；处理后轮询自动移除+Toast
- **专属验收**：① 三视图列结构差异（已办含处理结果、我发起含进度状态）；② 批量勾选 ≤50 上限提示；③ 排序规则=紧急度>剩余时间升序；④ 空态「太棒了，暂无待办」
- **工作量**：2d

### T1-04 UI-A1-03 消息中心

- **设计要点**：左分类（全部/待办提醒/审批结果/公告/系统通知，带未读计数）+ 右消息流
- **交互重点**：点击即已读；全部已读二次确认；带 jumpUrl 消息展示「查看详情」
- **专属验收**：① 未读红点与计数联动；② 分类切换保留滚动位置；③ 公告类跳公告详情
- **工作量**：1d

### T1-05 UI-M-01 移动首页（钉钉容器，**重构版 v2**）

- **设计要点（v2）**：375px 基准；问候+摘要 + **AI 简报（精简）** + 「**最要紧的一件事**」大卡 + **意图胶囊（横滑，取代旧金刚区）** + 我的订阅 + 其余待办流（权重递减）+ **底部 Tab 全局导航**
- **交互重点**：免登直达（无登录界面）；降级链展示（免登失败→静默 OAuth→登录页兜底）；顶部下拉唤起 AI
- **专属验收**：① **旧「金刚区」已移除**（不得回归 4 宫格）；② 「最要紧的一件事」大卡权重 ≥ 其余待办 ×1.5；③ 钉钉容器导航栏样式还原；④ 触控区 ≥44px；⑤ 底部安全区适配（`env(safe-area-inset-bottom)`）；⑥ 企微差异不出稿（决议 #2，标注说明即可）；⑦ **嵌入页面在移动端不渲染 iframe**（改「页面入口卡」，走新标签页语义，A1-F08-5）
- **工作量**：1.5d
- **状态**：**重构版 v2（新增结构，页面 ID 不变）**

### T1-06 UI-M-02 移动待办列表

- **设计要点**：Tab（待办/已办/我发起）+ 下拉刷新 + 卡片列表；左滑催办（提供等价按钮）
- **专属验收**：① 左滑操作与按钮等价（可访问性）；② 紧急度/超时视觉与 PC 一致；③ 空态插画移动版
- **工作量**：1d

### T1-07 UI-M-03 移动审批详情

- **设计要点**：标题+来源标签+发起人/时间+业务摘要 key-value+底部固定「去源系统处理」
- **专属验收**：① 底部操作栏固定且避让安全区；② 摘要字段过长折叠展开；③ V1.0 不做中台内直接审批（标注说明）
- **工作量**：1d

**批次 1 小计：11d**（1 名设计师约 2.5 周；里程碑：完成后组织第一次设计评审）

## 二、批次 2：管理端身份与主数据（8 页）

### T2-01 UI-C-01 账号管理

- **设计要点**：列表页范式；筛选 5 项；行操作（详情/重置密码/停用/强制下线）
- **交互重点**：新建账号弹窗（用户名规则实时校验、EmployeeSelect 关联、初始密码两种策略）；重置密码→随机密码一次性明文展示；强制下线显示当前会话数；详情抽屉（基本+角色+会话+登录历史）
- **专属验收**：① 随机密码关闭后不可再查看（文案明示）；② 停用/强制下线走 HighRiskConfirm；③ 状态标签三色（启用 success/停用 info/锁定 danger）；④ 操作全部写审计（标注）
- **工作量**：2d

### T2-02 UI-C-02 角色管理

- **设计要点**：左角色列表（含来源标签：系统预置/自建）+ 右详情三 Tab（基本/权限配置/成员）
- **交互重点**：权限配置=菜单树+API 权限点双 Tab 树形勾选（父子联动/半选态）；保存后生效提示；预置角色禁删、编码只读
- **专属验收**：① 半选态视觉正确；② 树节点搜索定位；③ 成员批量添加用 EmployeeSelect 多选；④ 权限保存提示「在线用户下次请求生效」
- **工作量**：2d

### T2-03 UI-C-03 权限点管理

- **设计要点**：左树右表范式（模块树+权限点表）；类型区分 menu/button/api
- **专属验收**：① api_pattern 展示支持通配符高亮；② 新建权限点校验编码唯一；③ 删除前校验「未被角色引用」否则阻断列原因
- **工作量**：1d

### T2-04 UI-C-04 在线会话管理

- **设计要点**：列表（账号/姓名/登录时间/最近活动/IP/终端）；单个+批量强制下线
- **专属验收**：① 强制下线 HighRiskConfirm+审计标注；② 当前登录者自己的会话标「本机」且不可下线；③ 自动刷新 60s
- **工作量**：1d

### T2-05 UI-C-06 组织管理

- **设计要点**：左树右表；组织树（搜索定位/悬浮操作：新增下级/编辑/停用）；右侧组织详情+下级组织
- **交互重点**：停用校验「无下级且无在职人员」否则阻断列出原因；**权威源=同步时全字段只读+顶部横幅**（决议落地关键）
- **专属验收**：① 只读横幅含「查看权威源配置」链接；② 树节点显示人数徽标；③ 物化路径面包屑（含生效期标识：当前/未来/历史）
- **工作量**：1.5d

### T2-06 UI-C-07 人员管理

- **设计要点**：左树（组织联动筛选）右表；详情抽屉（基本+任职+账号绑定状态+变更记录时间线）
- **交互重点**：无账号人员支持「开通账号」快捷操作（联动 T2-01 弹窗）；权威源=同步时只读
- **专属验收**：① 同步来源标签（钉钉/企微/HR/自建）；② 离职人员置灰+状态过滤默认「在职」；③ 时间线倒序含操作人
- **工作量**：1.5d

### T2-07 UI-C-08 权威源配置向导

- **设计要点**：3 步向导（选择来源→字段映射与同步策略→验证与启用）；来源卡片单选（钉钉/企微/HR/自建）
- **交互重点**：步骤 2 字段映射表（必填映射红星：姓名/工号/部门）+同步策略（频率/冲突规则）；步骤 3 连接测试日志流式输出+试拉取 10 条预览；启用确认弹窗（覆盖警告）；切换权威源需 super_admin+二次确认
- **专属验收**：① 每步校验不过禁用「下一步」；② 支持保存草稿；③ 测试失败展示可读错误（凭证/网络/格式分类）；④ 启用后组织人员页横幅联动（标注）
- **工作量**：2.5d（管理端最复杂页面）

### T2-08 UI-C-09 同步日志

- **设计要点**：列表（时间/来源/类型/结果/统计/耗时）+ 详情抽屉（字段级失败明细，可导出 CSV）
- **专属验收**：① 失败红色高亮+近 7 日失败统计卡；② 超阈值告警横幅；③ 明细表含源数据/期望格式/错误原因三列
- **工作量**：1d

**批次 2 小计：12.5d**（里程碑：完成后第二次设计评审，管理端列表页范式定稿，批次 3 复用）

## 三、批次 3：运营与集成（15 页，**含 3 页 v1.1 增补验收**）

### T3-01 UI-LOGIN-02 OIDC 授权确认页（0.5d）
应用图标+名称+scope 中文清单；已授权过提示；拒绝回跳 error=access_denied。**验收**：scope 描述面向普通员工可理解，不出现技术术语。

### T3-02 UI-LOGIN-03 忘记密码/重置（0.5d）
账号/手机验证→新密码（强度条实时反馈，对应密码策略）。**验收**：强度规则与 B1-F05 策略文案一致。

### T3-03 UI-LOGIN-04 MFA 验证页（0.5d，默认关闭态）
6 位验证码输入（自动聚焦下一格）、倒计时重发。**验收**：配置关闭时不可达（标注）。

### T3-04 UI-A1-02 应用中心（1d）
分组宫格（按业务域）+搜索+最近使用区。**验收**：无权限应用不展示；应用图标懒加载占位。

### T3-05 UI-A1-04 公告列表/详情（1d）
列表（置顶/未读标识）+详情（富文本、附件下载、已读回执统计-管理员视角）。**验收**：置顶红色 📢；详情页返回列表保留位置。

### T3-06 UI-U-01 个人设置（1.5d）

- **设计要点**：Tab：基本资料（只读，来自主数据）/ **首页布局**（入口跳首页编辑模式）/ **界面风格（新增）** / 通知偏好（渠道开关矩阵：待办提醒×钉钉/站内信…）
- **新增成员（界面风格 Tab，A1-F06）**：**主题色**（1 默认 + 4 预设：麓邦红 `#C8161D` / 靛蓝 / 石墨灰 / 暖橙 / 青竹绿，每档定义 primary/primary-light/primary-dark）/ **内容密度**（宽松/标准/紧凑，只改行高·内边距·区块间距·表格行高）/ **圆角**（直角/标准/圆润，映射 radius-sm/md/lg，**胶囊 9999px 三档不变**）；含**实时预览区** + 「保存风格」+「恢复默认风格」（二次确认）
- **交互重点**：选择后**即时全局生效并持久化**（原型 `localStorage: bmp_ui_style`；先应用本地再与服务端对齐防闪烁）；**恢复默认只清 `ui_style`，不得清空布局覆盖 `user_override`**
- **专属验收**：① 「首页布局」与「界面风格」两个 Tab 分工清晰（前者管布局、后者管视觉，可自由叠加）；② **不做暗色**（不预留入口、不做暗色预览）；③ **语义色不随主题色改变**（success/warning/danger、紧急语义红 `#C8161D`、渠道品牌色固定）；④ 保存后切换 Tab / 刷新仍保持；⑤ 主数据只读 +「修改请联系 HR」提示（决议：权威源单向）
- **状态**：**增补（界面风格 Tab 为本轮新增）**

### T3-07 UI-M-04 消息卡片落地页（0.5d）
消息全文+业务跳转按钮；容器返回行为适配。**验收**：钉钉卡片→落地页链路标注完整。
