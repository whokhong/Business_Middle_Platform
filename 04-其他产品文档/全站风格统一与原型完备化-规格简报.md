### 1.3 【决定性约束】旧页面对 `--bmp-*` 的依赖量

**实测：42 个 `--bmp-*` 变量、共 1268 处引用**（分布在 11 个旧页面 + common.css）。

完整清单：
```
颜色：--bmp-color-primary/-light/-dark  --bmp-color-success/-light  --bmp-color-warning/-light
      --bmp-color-danger/-light  --bmp-color-info/-light  --bmp-color-dingtalk  --bmp-color-wecom
中性：--bmp-text-title  --bmp-text-body  --bmp-text-secondary  --bmp-text-placeholder
      --bmp-border  --bmp-border-strong  --bmp-bg-page  --bmp-bg-card
字体：--bmp-font-family  --bmp-font-h1/h2/h3  --bmp-font-body  --bmp-font-caption  --bmp-font-number-lg
间距：--bmp-space-1/2/3/4/5/6/8
圆角：--bmp-radius-sm/md/lg  --bmp-radius-btn
阴影：--bmp-shadow-1/2/3
尺寸：--bmp-topbar-h  --bmp-console-menu-w
```

**结论：必须「保持变量名不变、只改值」** —— 改名会一次性炸掉 1268 处引用。

## 二、主理人架构裁定（关键决策，必须遵守）

### 裁定 1：Token 升级走「**双轨制**」——保留 `--bmp-*`，值指向 Notion 体系

`assets/tokens.css` 改为：

```css
:root {
  /* ===== Notion 暖色体系（新基准）===== */
  --surface: #f6f5f4;         /* 暖白（区块/卡片底，带黄褐底调） */
  --surface-hover: #efedea;
  --dark-surface: #31302e;
  --canvas: #ffffff;
  --text-primary: rgba(0, 0, 0, .95);
  --text-secondary: #615d59;
  --text-weak: #a39e98;
  --line: 1px solid rgba(0, 0, 0, .1);
  --line-color: rgba(0, 0, 0, .1);
  --accent: #C8161D;
  --accent-warm: #dd5b00;
  --r-card: 8px;  --r-pill: 9999px;
  --shadow-soft: rgba(0,0,0,.04) 0 4px 18px, rgba(0,0,0,.027) 0 2px 8px, rgba(0,0,0,.02) 0 .8px 3px;
  --shadow-lift: rgba(0,0,0,.08) 0 12px 28px, rgba(0,0,0,.04) 0 4px 10px;
  --font: Inter, -apple-system, "PingFang SC", sans-serif;

  /* ===== 兼容别名：旧页面 1268 处引用靠这些继续工作（值映射到新体系）===== */
  --bmp-color-primary: var(--accent);
  --bmp-color-primary-light: #FBECEC;      /* 保持浅红底（语义：品牌浅色强调） */
  --bmp-color-primary-dark: #A51218;
  --bmp-color-success: #16A34A;            /* 【固定】语义色不随风格变 */
  --bmp-color-success-light: #ECFDF3;
  --bmp-color-warning: #F59E0B;
  --bmp-color-warning-light: #FFFBEB;
  --bmp-color-danger: #F53F3F;
  --bmp-color-danger-light: #FEF2F2;
  --bmp-color-info: #64748B;
  --bmp-color-info-light: #F1F5F9;
  --bmp-color-dingtalk: #1677FF;
  --bmp-color-wecom: #07C160;
  --bmp-text-title: var(--text-primary);
  --bmp-text-body: #444;
  --bmp-text-secondary: var(--text-secondary);
  --bmp-text-placeholder: var(--text-weak);
  --bmp-border: var(--line-color);
  --bmp-border-strong: rgba(0, 0, 0, .18);
  --bmp-bg-page: var(--surface);           /* 关键：页面底从冷灰 #F1F5F9 → 暖白 #f6f5f4 */
  --bmp-bg-card: var(--canvas);
  --bmp-font-*: 沿用但统一字体栈为 var(--font)
  --bmp-radius-*: 值可微调（sm 4px / md 8px / lg 12px，与 Notion 一致，不必大改）
  --bmp-shadow-1/2/3: 值改为 Notion 多层低透明度阴影
  --bmp-space-*: 不变
  --bmp-topbar-h / --bmp-console-menu-w: 不变
}
```

**为什么这样最稳**：旧页面一行不用改，**只要 `common.css` 与 `tokens.css` 的值一变，11 个旧页面 + common.css 的样式自动变暖色系**。这是"改 2 个文件带动 34 处引用"的高杠杆做法。

### 裁定 2：`common.css` 同步适配（组件类暖色化）

- `body` 背景：`var(--bmp-bg-page)` → 自动变暖白（无需改页面）
- `.card`：去掉旧阴影，改用 `var(--shadow-soft)` + `1px solid rgba(0,0,0,.1)` 细边框
- `.btn` / `.btn-primary`：圆角与高度微调，primary 用 `var(--accent)`
- `.tag-*`：胶囊化（`--r-pill`）
- `.table`：表头底色改暖白 `#f8f7f6`，分隔线用 `rgba(0,0,0,.08)`
- `.field` input：细边框 + 聚焦用 `--accent`
- `.portal-topbar`：改为**毛玻璃**（`rgba(255,255,255,.72)` + `backdrop-filter: saturate(180%) blur(20px)`）
- **语义色不动**（success/warning/danger 保持原值）

### 裁定 3：语义色保护（延续既有决议）

- `--bmp-color-success/warning/danger` **及紧急语义红 `#C8161D` 全部固定**，不随主题色变（既有「界面风格定制」已立此规则）
- 暖色体系下避免"三种红打架"：**紧急/超时 → 品牌红**；**错误/失败 → danger 亮红**；两者职责区分
